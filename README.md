# TRIGGER ACTION

トリガーを組み合わせて戦う3Dアクション（試作）。ブラウザで動き、スマホではホーム画面に追加するとアプリのように全画面で遊べます。

## 遊ぶ

GitHub Pages の公開URL（例：`https://ユーザー名.github.io/trigger-action/`）を開くだけです。

- **スマホ**：開いたら、iPhone は共有ボタン →「ホーム画面に追加」、Android は メニュー →「アプリをインストール」（または「ホーム画面に追加」）。横持ちの全画面で起動します。
- **一度開けば**：ネットにつながっていなくても起動できます（オンライン対戦だけはネットが必要）。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム本体（1ファイル。中の目次から各部へ飛べる） |
| `manifest.webmanifest` | アプリとしての名前・アイコン・横向き・全画面の設定 |
| `sw.js` | 一度読み込んだ物を保存して、ネットなしでも起動できるようにする裏方 |
| `icon-192.png` `icon-512.png` `icon-512-maskable.png` | アイコン（192px・512px・Android用の余白つき）。スマホからでも上げやすいよう、フォルダに入れず一番上に置く |

## 公開のしかた（はじめて）

1. GitHub で新しいリポジトリを作る（例：`trigger-action`、Public）。
2. このフォルダの中身（`index.html` `manifest.webmanifest` `sw.js` `README.md` と、アイコン3つ）を全部アップロードする（「Add file」→「Upload files」に、まとめてドラッグ）。
3. リポジトリの「Settings」→「Pages」→「Build and deployment」で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして「Save」。
4. 1〜2分待つと、同じ画面の上に公開URLが出る。

## 新しい版に入れかえるとき

1. 新しい版の HTML を `index.html` という名前にして上書きアップロードする。
   （このフォルダの `index.html` には、アプリ用の数行（`manifest` と `sw.js` を読む行）が足してあります。新しい版にも同じ行を入れてください。Claude に「アプリ用にして」と頼めば入れます）
2. `sw.js` の `VERSION`（例：`'ta-v0.84'`）を新しい版の番号に変える。これを変えないと、古い版が保存されたまま残ることがある。
3. スマホで一度アプリを開き直すと、新しい版になる（すぐ変わらないときは、もう一度開き直す）。
